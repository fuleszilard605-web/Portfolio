Featured project · Unity & C#

Serious Game Prototype Development

A collaborative project to design and develop a functional prototype of a cognitive rehabilitation game for older adults, focusing on memory.

Project overview image

Project overview

Developed as part of a four-person team with assigned research, design, and development responsibilities. I worked as one of the developers, contributing to the implementation of the Unity and C# prototype.

Academic Award for the final deliverable

Project aims

The project explored the development of a game-based tool intended to support memory rehabilitation in an elderly population. The prototype needed to provide a functional experience while considering accessibility and the needs of its intended users.

My role

As a developer, I worked with Unity and C# to help implement the functional prototype. The group project involved collaboration between research, design, and development roles, alongside Git and GitHub version control.

Development considerations

  • Translating design ideas into feasible functionality.
  • Considering accessibility and the intended user group.
  • Collaborating across different project roles.
  • Using object-oriented programming and debugging.
  • Working within the scope and deadlines of a group project.

Skills and technologies

Unity, C#, object-oriented programming, Git/GitHub, collaborative development, debugging, problem-solving, software prototyping, and accessibility-focused design.
